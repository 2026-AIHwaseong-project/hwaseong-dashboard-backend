# 화성시 버스 수요·공급 미스매칭 대시보드 — 백엔드

> 26년 여름학기 AI화성챌린지 대학생 솔루션데이 · 과제 23번(교통분야)
> 프론트엔드: [hwaseong-dashboard](https://github.com/2026-AIHwaseong-project/hwaseong-dashboard)

## 시작하기

```bash
git clone https://github.com/2026-AIHwaseong-project/hwaseong-dashboard-backend.git
cd hwaseong-dashboard-backend

pip install pandas duckdb requests python-dotenv openpyxl
# 담당 A 추가:  pip install pyshp shapely pyproj scikit-learn
# 담당 B 추가:  pip install fastapi uvicorn sqlalchemy alembic psycopg2-binary

cp .env.example .env      # 발급받은 공공데이터포털 키를 넣으세요
python analysis/check_api.py
```

`check_api.py` 가 전부 PASS 면 준비 완료입니다.

## 수요 정의 변경 (2026-08-12)

`03_join.py` 의 승차 집계를 두 군데 고쳤습니다. 상세는 같은 파일 docstring [4][5].

| | 이전 | 이후 |
|---|---|---|
| 승차 기준 | `승차합계` (환승 포함) | **`초승`** — 환승 제외 |
| 일평균 기준 | 119일 통짜 평균 | **평일 85일** 평균 |
| 일평균 승차 | 169,026 | **150,828** (−10.8%) |

**왜 환승을 빼는가.** 승차합계 2,025만 = 초승 1,650만(81.5%) + 환승 375만(18.5%)입니다.
환승은 새로 발생한 통행이 아니라 이미 버스에 탄 사람이 갈아탄 것입니다. 이걸 수요로
세면 철도 연계 격자의 D 가 통째로 부풉니다 — 환승비가 병점역후문 71.2% · 어천역 77.1% ·
야목역 81.7% 이고, 환승비 30% 이상인 66개 정류장이 전체 승차의 21.1% 를 차지합니다.

**왜 평일인가.** 주말 승차는 평일의 68.3% 이고 그 비율이 정류장마다 0.06(반월중·고등학교앞)
부터 3.59(석포산업단지)까지 약 60배 벌어집니다. 119일을 통으로 평균내면 평일 기준 대비
중앙 −10.7%(범위 −25%~+47%) 어긋납니다. am(07-09)·pm(17-19)은 통근 시간대라 평일이
맞는 자입니다. 주말분은 `board_day_we` 로 남겨 뒀습니다 — 요일축 도입 때 씁니다.

**영향.** 4분면 need 28/28/30/42 → **32/31/31/43**, 홀드아웃 로그 R² 0.842 → 0.838
(원단위는 0.801 → 0.874 로 개선), 배차 탄력성 +0.608 → **+0.551**.

## ⚠️ 정성 대조가 미달입니다 — 발표 전 조사 필요

`07_validate.py` [3-1] 이 매 실행마다 공개근거와 **현재** 우선순위를 대조합니다.
예전에는 순위를 손으로 적어 뒀는데, 노선 커버리지를 보강(140→200)하자 새솔동이
need 에서 빠졌는데도 문구는 "출근 1·4위 ✅" 로 남아 있었습니다. 이제 순위는 하드코딩하지
않고 산출물에서 계산합니다.

현재 상태 — **공개근거 2건이 모두 Top5 밖입니다.**

| 읍면동 | 공개근거 | 현재 순위 |
|---|---|---|
| 새솔동 | ✅ 경기일보·나무위키 | 출근 27/32위 · 심야 need 아님 |
| 비봉면 | ✅ 나무위키 | 출근 need 아님 · 심야 8/43위 |
| 화산동 | ⬜ 못 찾음 | 출근 24/32위 · 심야 26/43위 |
| 정남면 | ⬜ 못 찾음 | 출근 22/32위 · 심야 15/43위 |

발표에서 *"모델이 찍은 곳이 실제로 문제인 곳"* 이라고 말하려면 **현재 Top5 읍면동**에
대한 공개자료 조사가 필요합니다: 출근 `남양읍·동탄7동·동탄9동·봉담읍`,
심야 `동탄7동·동탄9동·봉담읍·진안동·향남읍`.
